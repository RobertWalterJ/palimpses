# Palimpsest

A phone history-learning app. History told from several centres rather than one
European baseline: each pack starts from its own people, on their own terms.
Canada first, then the Caribbean, then Ireland and Britain.

    node build/extract.mjs   # open textbooks -> corpus/ (every paragraph, citable)
    node build/verify.mjs    # every question checked against its source, verbatim
